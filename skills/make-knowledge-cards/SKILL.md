# Make Knowledge Cards

## 概述

把文章内容转化为一组结构化的知识卡片，每张卡片只承载一个知识点，帮助用户快速理解、记忆与复习。

本 Skill 不支持：网页抓取、PDF 文件、Anki 导出、图形界面。遇到这类需求，简短说明不支持即可，不要尝试执行。

## 输入

- 对话中直接粘贴的文章文本；
- 本地 `.md` / `.txt` 文件：先读取文件内容，忽略纯排版标记（标题层级、加粗、链接等），保留表格、代码块、引文等实质内容。

## 工作流程

### 1. 读取并理解全文

通读全部输入，确认文章主题与结构（分节/分段/分论点），建立完整脉络后再开始提炼。

### 2. 提取候选知识点

逐个知识单元判断，满足以下任一条即可入选：

- 支撑文章主旨的关键概念、机制或论点；
- 有信息增益、可独立理解并迁移使用的知识；
- 原文明确给出的重要事实、数据或方法。

排除：铺垫性背景、修辞与情绪化表达、重复强调、无关细节。

### 3. 筛选、去重、定数量

- 合并语义重复的知识点，只保留表述最完整的一条；
- 按重要程度从高到低排序，最终输出 **5~8 张**卡片；
- 若原文信息量不足以支撑 5 张，如实减少数量（如 3~4 张），并在输出开头注明“原文信息有限”；绝不编造内容凑数。

### 4. 撰写卡片

每张卡片严格使用下文“卡片格式”，一张卡片只讲一个知识点，四个字段缺一不可。

### 5. 输出

一次输出全部卡片，按重要性从高到低排列；输出语言跟随原文语言。

## 输出结构

一次输出的完整结构如下，首行与数量说明必不可少：

```markdown
# 知识卡片｜来源：《<文章标题>》｜共 N 张

> 说明：<仅当 N < 5 时出现，写明“原文信息有限”及原因>

## 卡片 1｜<标题>
……
```

- 来源标题：优先用原文标题；粘贴文本无标题时，用一句话概括，并标注“概括标题”。
- 不足 5 张时，在来源行下用引用块说明原因，再输出卡片。

## 卡片格式

每张卡片四个字段缺一不可：

```markdown
## 卡片 N｜<标题>

**核心知识**：<一句话陈述该知识点>

**简明解释**：<2~4 句，忠于原文的展开解释>

**例子/自测**：<优先引用原文中的例子；原文无例可引时，出一道基于原文内容的自测题，并确保答案可从原文得出>
```

若采用自测题，可在题后括号内附参考答案，答案必须能从原文直接得出。

## 质量规则（必须遵守）

1. **只提取真正重要的知识**：不把修辞、背景铺垫和琐碎细节做成卡片。
2. **一张卡片只讲一个知识点**：同一知识点只做一张卡片，不拆分凑数。
3. **删除重复内容**：多个位置重复出现的观点只保留一张卡片；若原文重复明显，可在对应卡片中简要注明“已合并重复表述”，提升可追溯性。
4. **不编造**：卡片内容必须在原文中找得到依据；原文没有的信息一律不写，不做过度引申。
5. **信息不足时不凑数**：少于 5 张是允许的，必须说明原因；候选超过 8 张则重新合并去重。纯叙事、抒情类文章知识密度低，允许只产出 1~2 张卡片。

## 边界

- 网页链接（需抓取）、PDF、Anki、图形界面：简短说明“该 Skill 不支持此项”，不执行。
- 输入为空或内容过少（如不足 100 字）：说明输入过少，无法生成有效卡片。
