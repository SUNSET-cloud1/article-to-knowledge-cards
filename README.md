# make-knowledge-cards

把文章转换为 **5\~8 张知识卡片**的开源 Skill。每张卡片包含：标题、核心知识、简明解释、例子或自测题，适合学习笔记、知识整理与复习。

## 功能



* **输入**：对话中粘贴的文章文本，或本地 `.md` / `.txt` 文件

* **输出**：按重要性排序的 5\~8 张 Markdown 知识卡片

* **质量约束**：只提取真正重要的知识；一张卡片只讲一个知识点；自动合并重复内容；不编造原文没有的信息；信息不足时如实减少数量，不强行凑数

**暂不支持**：网页抓取、PDF、Anki 导出、图形界面。

## 目录结构



```
skills/make-knowledge-cards/

├── SKILL.md            # Skill 定义：输入规则、工作流程、卡片格式、质量规则、边界

└── agents/

&#x20;   └── openai.yaml     # UI 元数据（显示名、简介、默认提示词）
```

## 使用方法

在对话中直接提出需求，两种输入方式：



1. **粘贴文本**：把文章内容直接贴在请求里，例如：

> 请把下面这篇文章做成知识卡片：<粘贴文章全文>



1. **本地文件**：提供 `.md` 或 `.txt` 文件路径，例如：

> 帮我读取 tests/inputs/01-compound-effect.md，并整理成知识卡片

## 输入输出示例

**输入**（文章节选）：

> 每天进步 1%，一年后大约是原来的 37.8 倍；反过来，每天退步 1%，一年后大约只剩原来的 0.03。这个对比说明：微小的日常差异，在时间的复利作用下会被放大到天壤之别。

**输出**（卡片节选）：



```
\## 卡片 3｜微小差异会被复利放大成天壤之别

\*\*核心知识\*\*：每天进步 1%，一年后约是原来的 37.8 倍；每天退步 1%，一年后只剩约 0.03。

\*\*简明解释\*\*：按 365 天连续计算，1.01 的 365 次方约等于 37.8；0.99 的 365 次方约等于 0.03。日常看似微小的差别，经过时间叠加后差异巨大。原文同时给出按 250 个工作日计算约为 12 倍的口径。

\*\*例子/自测\*\*：例子：每天进步 1% 与每天退步 1%，一年后分别为约 37.8 倍和约 0.03，几乎归零。
```

## 测试

`tests/inputs/` 下准备了 5 篇不同类型文章（科普机制、观点论证、叙事散文、操作指南、极短文本），用于验证知识提取、去重、数量控制与边界处理；对应输出见 `tests/outputs/`。Skill 结构已通过官方 `quick_validate.py` 校验（`Skill is valid!`）。
